# العشرون: الخصوصية والأمان

- لا تجمع الموقع إلا بعد موافقة المستخدم.
- اجعل بيانات العبادات محلية ومشفرة.
- وفر خيار استخدام التطبيق دون إنشاء حساب.
- وضّح سبب كل صلاحية.
- لا تستخدم البيانات لأغراض إعلانية حساسة.
- وفر حذف الحساب والبيانات.
- لا تسجل الصوت إلا بعد إذن واضح عند استخدام التسبيح الصوتي.
- اجعل كل الخدمات الخارجية قابلة للتعطيل.

# العبارة النهائية للمصمم أو أداة بناء التطبيق

أنشئ تطبيقاً إسلامياً شاملاً وفاخراً، يجمع بين جمال التصميم وسهولة الاستخدام وعمق المحتوى، مع واجهة عربية حديثة مستوحاة من الألوان الداكنة والزخارف الإسلامية والبطاقات الزجاجية. اجعل التطبيق عملياً للاستخدام اليومي، سريعاً، واضحاً، ويعمل دون اتصال في الوظائف الأساسية. لا تكتفِ بتصميم الشاشات فقط؛ قم ببناء تدفقات الاستخدام والمنطق الوظيفي لكل ميزة، مع حالات التحميل والخطأ والبيانات الفارغة، واحرص على أن تكون جميع النصوص والمصادر والملفات الصوتية والصور قانونية وموثوقة وقابلة للإدارة والتحديث.

**النتيجة المطلوبة:** تطبيق إسلامي متكامل بهوية مستقلة، يضم القرآن والتلاوات والتفسير والحفظ والأذكار والتسبيح ومواقيت الصلاة والقبلة ومنبه الفجر وصلاتي والخطط التعبدية والإذاعات والسيرة والحج والعمرة والمساعد الإسلامي والويدجت والخلفيات، مع تجربة استخدام احترافية تشبه جودة التطبيقات العالمية دون نسخ أي علامة تجارية أو أصول مملوكة.
